# ?? TallyConverter (Cloud Web App on GitHub Pages)

> **Professional Excel to Tally XML Converter for TallyPrime & Tally.ERP 9**  
> Designed and Made by Santhosh

Live standalone web application hosted 100% on **GitHub Pages**.

---

## ?? Features
- **Bank Statement Formatter**: Automatically classifies bank statements into **Receipts**, **Payments**, **Receipt Contra**, and **Payment Contra**, and maps ledgers seamlessly into Tally format.
- **Dynamic Live Spreadsheet Preview**: Visualizes uploaded Excel/CSV columns and rows with accurate macOS-style window metrics.
- **Encrypted PIN Security**: Client-side authentication hashed with `SHA-256` and unique cryptographic salt via native Web Crypto API.
- **28 Official Tally Groups**: Smart ledger de-duplication and group mapping.
- **Day & Night Themes**: Sleek Apple-inspired design with dark and light modes.
- **Quick Accountant Calculator**: Built-in floating calculator with tape history and paste shortcuts.
- **100% Offline & Private**: Zero data is sent to external servers; all operations execute in browser memory.

## ?? How to Host on GitHub Pages (1-Click)

1. Create a new GitHub repository (e.g. `tally-converter`).
2. Upload the contents of this folder directly to your repository root (`main` branch).
3. In your GitHub repository:
   - Go to **Settings** $\rightarrow$ **Pages**.
   - Under **Build and deployment** $\rightarrow$ **Source**, choose **Deploy from a branch**.
   - Select Branch: **`main`** and Folder: **`/ (root)`**.
   - Click **Save**.
4. Your site will immediately be live at:
   `https://<YOUR_USERNAME>.github.io/<YOUR_REPOSITORY>/`
